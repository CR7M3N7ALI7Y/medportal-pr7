# MedPortal — запись к врачу и ведение истории приёмов

Вариант 1. Практическая работа №7 «Разработка элементов графического дизайна приложения».

Медицинское веб-приложение для онлайн-записи к врачу и ведения истории приёмов. Дизайн адаптирован под смартфон **390×844 px**, выполнен в медицинской палитре: белый, бирюзовый, светло-серый.

## Структура проекта

```
MedPortal/
├── index.html          # Главная — Hero, быстрые действия, услуги
├── register.html       # Регистрация (ФИО, СНИЛС, дата рожд., email, пароль)
├── login.html          # Авторизация
├── profile.html        # Личный кабинет — история приёмов, отзыв
├── application.html     # Формирование заявки (каскадные списки + дата)
├── admin.html          # Панель администратора — фильтры, карточки заявок
├── css/
│   └── styles.css      # Единые стили, медицинская палитра
├── js/
│   ├── validation.js   # Валидация форм, проверка уникальности логина
│   └── admin-filter.js # Фильтрация и карточки заявок
├── img/
│   ├── icons/          # Иконки интерфейса (11 шт.)
│   └── photos/         # Графика MedPortal (логотип, баннер, врачи)
└── README.md
```

## Реализованный функционал

| Страница | Возможности |
|---|---|
| `register.html` | Валидация ФИО, СНИЛС (формат + контрольная сумма), даты рождения, email, пароля (буквы+цифры от 6 симв.), повтор пароля. Проверка уникальности логина через `localStorage`. Ошибки под полями (красный текст + красная рамка). |
| `login.html` | Авторизация по email и паролю с проверкой учётных данных. Сессия сохраняется в `localStorage`. |
| `profile.html` | Личный кабинет. Карточка пациента, статистика приёмов, история приёмов. **Кнопка «Оставить отзыв» доступна только если приём завершён** (`event.finished === true`). Звёздная оценка + текст. Защита от несанкционированного доступа (`data-guard="auth"`). |
| `application.html` | Каскадные выпадающие списки «Специальность → Врач → Филиал», поле выбора желаемой даты (минимум завтра), динамические временные слоты, поле комментария, согласие на обработку ПД. Заявка сохраняется в `localStorage` и доступна в админ-панели. |
| `admin.html` | Карточки заявок с цветной левой полосой и бейджами статусов. Фильтры: поиск, статус (чипы), специальность, врач, диапазон дат. Действия: «Завершить», «Отменить», «Вернуть в ожидание». KPI-сводка. |

## Технологии

- HTML5, CSS3 (flexbox, grid, CSS-переменные)
- Ванильный JavaScript (ES6+, без фреймворков)
- `localStorage` — имитация БД пользователей и заявок
- Google Fonts (Inter)
- Шрифты иконок — PNG из поставки

## Доступность

- Контрастные цвета текста (WCAG AA)
- Видимый `:focus-visible` на интерактивных элементах
- Семантические `<label>` и `aria`-атрибуты форм
- Поддержка `prefers-reduced-motion`

## Как запустить локально

Открыть `index.html` в браузере. Для эмуляции экрана 390×844 — DevTools → Toggle device toolbar → iPhone 12 Pro (390×844) или аналогичное устройство.
